# Getting help

| You want to | Go to |
|---|---|
| Understand what Genoryn Krypton is | [genoryn.io/about](https://genoryn.io/about) and the [FAQ](https://genoryn.io/faq) |
| Install the wallet, mine, swap, run a node | [Documentation](https://genoryn.io/docs) and the [README](README.md) |
| Fix a problem | [Troubleshooting](https://genoryn.io/docs#troubleshooting) |
| Ask the community, talk mining and swaps | [Genoryn Talks](https://genoryn.io/talks): the forum and live chat |
| Report a bug or ask a question | [Open an issue](https://github.com/genoryn/genoryn/issues/new/choose) |
| Report a vulnerability | [Privately](https://github.com/genoryn/genoryn/security/advisories/new), never in a public issue |

Before you open an issue, include the wallet version (About tab), your operating system and
what you did, expected and saw.

**Never post your recovery phrase, password or wallet file.** Nobody from the project will
ever ask for them.
