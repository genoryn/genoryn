# Roadmap

What is planned, and nothing else. There are no dates: a step ships when it is reviewed and
tested. Changes to the rules of the chain are announced ahead of time with the block at which
they activate; nothing changes the rules by surprise.

## Planned

| Step | Status |
|---|---|
| **Quantum tokens**: designed and coded with tests and a public [specification](spec/assets.md) | Done |
| Quantum tokens: review, then a release that names the activation block (a consensus upgrade) | Next |
| Quantum tokens: deploy, send and trade tokens in the wallet's Tokens tab | After activation |
| Recursive proof aggregation per block | Planned |
| Prebuilt GPU kernels per architecture | Planned |
| More independent public nodes | Planned, and anyone can help ([run a full node](https://genoryn.io/full-node)) |
| External security audits | Planned ([SECURITY.md](../SECURITY.md)) |

## Being worked on

| Step | Status |
|---|---|
| Website and wallet in ten languages | Machine translations shipped; review by people who speak them welcome ([guide](localization/README.md)) |
| Hive OS custom miner package | Tested on Ubuntu 20.04 and a devnet node; waits for reports from real rigs ([guide](hiveos/README.md)) |
| Mining calculators and pool trackers | Prepared, not submitted; they require a market on a supported exchange ([status](../integrations/mining-listings/listing-status.md)) |

## Not planned

- Mining pools, pool fees or a developer fee: the protocol pays every miner by shares.
- A premine, a presale or any allocation.
- Changes to the emission schedule or the 21,000,000 GNR cap.
