# Genoryn Krypton 1.0.53: implementation, tests, benchmarks and decentralization

Report for the 1.0.53 release. No consensus rule, emission or reward rule changed; nodes and
wallets of earlier versions keep working with this one. Trading stays GNR/BTC only.

## What was built

| Area | What changed | Where |
|---|---|---|
| Trade history | Every completed swap is stored on disk by the node (`swap-history.redb`), imported once from the old JSON file (kept as a backup). Pages by offset and time, a cached summary per day. The wallet loads at most 200 swaps for its charts and shows the rest in pages; genoryn.io/trades shows the whole history. | `apps/kryptond/src/history.rs`, `swapboard.rs`, `apps/krypton-wallet/src/trades.rs`, `website/trades.*` |
| Market price | Method `gnr-price-2`: windows of 24 h (when busy), 72 h, 7 d and 30 d; at least three verified swaps of 0.001 BTC; time decay; outliers removed by a 4× rule and a 5×MAD rule; caps per swap's GNR worth, per swap (a fifth) and per six-hour block (a quarter); weighted median; rebuilt hour by hour with a 10 % hourly limit; confidence 0 to 100 from liquidity, effective swaps, spread and freshness; seven statuses. Integer arithmetic only, so every node computes the same price; the wallet's `verifymarketprice` recomputes it. | `crates/krypton-swap/src/price.rs`, `docs/spec/market-price.md` |
| Market display | Status, confidence, 24 h change, freshness and a depth chart in the wallet and on genoryn.io. | `ui.html`, `website/market.*`, `site.js` |
| Confirmations | Bitcoin payments previewed (network, amount, fee, total, what stays) before the password; one payment at a time; swap terms at a glance before taking an offer or a Quick Swap. | `ui.html`, `board/quick.rs` |
| Tor | An optional `socks5h` proxy for every connection the wallet makes itself; loopback stays direct; the node and the miner it starts are not given it; changing it needs the password. | `apps/krypton-wallet/src/proxy.rs` |
| Security | The 27 findings of the [1.0.53 audit](../audit/2026-11-26-system-audit-1.0.53.md), and the items the [1.0.52 report](../audit/2026-11-26-full-audit.md#fixed-in-1053) held back. | see the reports |
| Server | Caddy takes the client address from Cloudflare's header only for Cloudflare's ranges; the BTC price request carries nothing about the visitor. Deployed with an automatic revert, verified, then kept. | `deploy/caddy/genoryn.io.caddy` |
| Research | Transaction metadata on mainnet, and Sietch. | `docs/research/privacy-sietch.md`, `tools/chain-metadata` |

## Decentralization assessment

Measured on mainnet on 26 November 2026, over the last 1,440 blocks (24.2 hours):

| Measure | Value |
|---|---|
| Distinct miners that found a block | 53 |
| Largest miner's share of blocks found | 14.1 % |
| Three largest together | 36.9 % |
| Shares credited (each pays its miner directly) | 46,876 |
| Peers of the public node | 47 |

**What is not centralized:**

* **Mining** has no pool. Every block's reward is split among all miners by their share of the
  work, so a small miner earns its exact share every block, paid by the chain itself. No
  operator holds miners' coins, and no block finder can redirect the payouts.
* **The rules** are enforced by every node; light wallets now check every block above the
  checkpoint themselves. A wallet can read from several nodes, or from its own.
* **The market price** is computed the same way by every node from swaps whose bitcoin is on the
  Bitcoin chain, and anyone can recompute it.
* **Swaps** are atomic: neither the board nor any node can take or hold the coins.

**What still depends on one operator, and what can be done:**

| Dependency | Effect if it is gone or dishonest | Mitigation today | Next step |
|---|---|---|---|
| The built-in seeds are one server's address (the second, `seed.genoryn.io`, does not resolve at the moment) | New nodes find peers more slowly | Nodes remember peers; `--peer` adds others | Seeds run by independent operators |
| genoryn.io is the default node of light wallets | Wallets wait until another node is set; a dishonest default can no longer show cheap fake blocks (1.0.53) | Several nodes can be set and are cross-checked; a full node in one click | More public nodes listed in the wallet |
| The offer board runs on the nodes the wallet reads | No new swaps until another board is reachable; running swaps finish on chain | Any node is a board | Wallets that read several boards |
| One release key signs updates | Updates stop if it is lost; a stolen key could sign a bad update | Hybrid post-quantum signature, key fingerprint published | Threshold signing by several people |
| The BTC price comes through genoryn.io | Dollar values are not shown | Prices in BTC need nothing | A second source, and the node's own |

None of these touches the chain's rules or anyone's coins; each one is about how quickly a user
can reach the network, not about who controls it.
