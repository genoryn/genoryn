# GENORYN 1.0.4

A wallet update for Mainnet 1.0. Consensus, the chain, the node and wallet files are
unchanged; update by running the new installer (wallets are kept).

## Wallet

- **Up to 10,000 wallets.** Remembered wallets unlock and scan in batches: one wallet
  process opens 250 wallets at a time, derives their keys in parallel, reads new blocks
  once (from your own node, or from the chain verified on this computer in Quick mode) and
  updates every wallet's encrypted scan cache from them. A progress bar shows how many are
  unlocked. A wrong password or a missing file affects only that wallet.
- **New Wallets page**, second in the menu: every open and remembered wallet with its
  balance, spendable amount, scanned block and state, **richest first** by default.
  - Search by name or folder; sort by balance (highest or lowest first), name or scanned
    block; filter All, Open, Locked or Need attention; pages of 100.
  - Totals for all open wallets: balance, spendable now, open and locked counts.
  - Switch to a wallet, lock it, scan it now, unlock a locked one with its own password or
    the active wallet's password, or remove it from the list (the file is never touched).
  - **Import a folder of wallets**: every `.gnr` file in a folder is added and unlocked with
    the active wallet's password when it matches.
- The Overview lists the **10 richest** other wallets and links to the full list; the
  wallet menu at the top shows the 12 richest.
- When other open wallets receive funds, one notice sums them up.

## Wallet CLI

- New `sync_batch` operation (JSON stdio): up to 10,000 `{wallet_path, password}` entries
  in one request, compact per-wallet results. Requests may now be up to 16 MiB.
