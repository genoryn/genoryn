# GENORYN 1.0.5

A wallet update for Mainnet 1.0. Consensus, the chain, the node and wallet files are
unchanged; update by running the new installer (wallets are kept).

## Payment proofs

- **One step after paying.** After a payment, the Send page offers **Create payment proof**.
  The wallet finds the payment's own output by itself (never your change) and gives the proof
  in three forms: a **text code** (`GNRPROOF1-…`) to paste into any message, a **PDF** to
  send or print, and a **JSON** file. A proof can be made right after sending, before the
  payment is mined.
- **Made by the sender.** A proof from the paying wallet now carries that output's outgoing
  cipher key, which only the sender's wallet can derive. The verifier sees "Made by the
  sender"; a recipient cannot produce such a proof. No spending key or viewing key is
  disclosed.
- **New Verify payment page.** Paste the code or JSON, choose the PDF or JSON file, or drop
  it onto the window, optionally enter the address the payment should have gone to, and press
  Verify. The wallet checks the proof against the chain and answers plainly:
  - real payment found in block N, with confirmations, amount and memo;
  - "Yes — this payment went to the address you entered" or "No — this payment did NOT go to
    the address you entered";
  - whether it was received by your open wallet;
  - whether the sender made the proof.
- Proofs also work in Quick mode (over Tor).

## Large payments and the 16-note limit

A transaction can spend at most 16 notes, and every block reward is one note. The Send page
now shows when an amount needs more and how much one payment can send right now, with a
**Combine notes now** button: the wallet sends your notes to yourself, 16 at a time, paying
only the network fee. After the next block, send the payment again.

## Wallets

- **The same wallet cannot be added twice.** A wallet opened, restored or unlocked under a
  second file name is recognised by its address and not added again (restoring refuses before
  any file is written); on the Wallets page such a file shows "Same wallet as …". Totals never
  count a wallet twice.
- The Wallets page table no longer runs past the window: below the width the full table
  needs, each wallet takes two lines. Filters show their counts.
- The menu fits ten entries; the status line no longer overlaps the scan indicator.
