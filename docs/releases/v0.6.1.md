**Mainnet release. The software has not been independently audited: mine or hold only what you can afford to lose.**

GENORYN 0.6.1 fixes two problems found right after 0.6.0: Tor-only nodes that could not
find any peer, and usernames typed without `@`. Everyone on 0.6.0 should update.

### Tor-only nodes find the network on their own

- Two mainnet onion seeds are now built in: the genoryn.io node and seed 187.7.72.137.
  A new Tor-only installation reaches them through Tor without exits and syncs within
  about a minute of Tor being ready.
- The published seed lists (`seeds/mainnet.txt`, `seeds/mainnet-onion.txt`) get enough
  time over Tor. 0.6.0 gave up after 5 seconds, often before Tor had built its first
  circuit, and was then left with peers that Tor exits do not reach: the wallet showed
  "Tor works, but no peer could be reached through it yet" and the node stayed behind.
  Both lists are now fetched together, each with up to two 30-second attempts.

If you stay on 0.6.0 for now in Tor-only mode and see that warning, choose **Hybrid** on
the Network page until you update.

### Sending to a username

- A username can be typed with or without `@`: `genorynadmin` now pays the same receiver
  as `@genorynadmin`, as registered on the chain. 0.6.0 read the bare name as an address
  and failed with "parse failed".
- Text that starts like an address of this network (`gnr1…`) still needs the `@`, so a
  cut-off address is never taken for someone's name.
- An invalid recipient now says so: "the recipient is neither a GENORYN mainnet address
  nor an @username".

### Unchanged

Peer protocol, consensus, monetary rules, wallet files and chain data are unchanged:
0.6.1 works with 0.4.x, 0.5.x and 0.6.0 nodes.

### Upgrading

Run `GENORYN-Setup-0.6.1.exe` (or the Lite installer) over your current installation;
wallets and chain data are kept. The wallet's **Settings → Updates** card offers it too.

GENORYN is not code-signed yet. If Windows 11's Smart App Control is on, the installer
explains how to turn it off. SmartScreen's "Windows protected your PC" prompt: choose
**More info → Run anyway**.

### Verify before running

Every installer and archive has a matching `.sha256` file; each package contains
`SHA256SUMS` and `release-manifest.json` with the exact source commit and edition.
Packages are **unsigned builds**.
