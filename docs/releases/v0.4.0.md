**Mainnet release. The software has not been independently audited: mine or hold only what you can afford to lose.**

GENORYN 0.4.0 launches the real network. The mainnet starts at block 0 with a fair
launch: no premine, no founder coins, and the treasury share is burned. Every program
now joins the mainnet by default.

- **Fair launch.** The treasury's 1 GNR per block (heights 1–210,000) is paid to a
  provably unspendable address whose key comes from hashing to the curve. Nobody,
  developers included, can spend it. At most 20,790,000 GNR can ever circulate.
- Mined coins mature after 60 blocks.
- The node, miner, CLI wallet and desktop wallet all default to mainnet. The devnet and
  testnet remain only for development labs and automated tests.

### Usernames on the chain

- **Register `@you` once and forever.** Receive → Username shows as you type whether a
  name is free, being registered or taken, and what it costs. A confirmation lists the
  burned amount and what becomes public before anything is sent.
- **One global answer.** Every node derives the same name table from the chain: the
  first valid registration wins and nobody can take the name afterwards. Pay anyone with
  `@name`; the wallet resolves it through your own node and shows the address.
- **Burned prices against squatting:** 3–4 letters 1,000 GNR, 5–6 letters 100 GNR,
  7 or more 10 GNR, sent to the same provably unspendable burn address.
- **Payments stay private.** A name publishes only the address it points to, a separate
  address of your wallet, never your main one. Who pays you and how much stays shielded.
- Node RPC: `GET /v1/names?name=` and `GET /v1/names/owner?owner=`. CLI: `name_status`,
  `register_name`, `update_name`, `my_names`. Specification:
  [on-chain usernames](https://github.com/genoryn/genoryn/blob/main/docs/protocol/usernames.md).

### A wallet that never freezes

- **Scans run in the background** in their own lane, shown at the bottom right, and never
  disable sending, registering or anything else.
- **Incremental sync.** With your own node, the wallet keeps an encrypted scan cache and
  reads only new blocks: about 0.2 seconds instead of a full re-scan that grows with every
  block. Results are identical to the full validating scan. Forks roll back to the shared
  block; Rescan history rebuilds from the first block.

### Mining that explains and repairs itself

- When the miner stops, the Mining page says why in plain words: the node refused the
  admin token (usually another node on the same port), the node did not answer, the
  node runs a different network, or RandomX could not start.
- When a fix exists, the wallet applies it and restarts automatically, at most three
  times: portable RandomX mode for CPUs or security software that refuse the JIT
  compiler, and half the threads when memory runs out.
- Executables that are missing or blocked by security software are named, with the fix.
  Mining never needs administrator rights, and the wallet never asks for them.
- The miner waits up to two minutes for a node that is still starting instead of
  exiting, and stops with a clear reason on a refused token instead of retrying forever.
  Each failed run ends with `genoryn-miner stopped [kind]: reason` in its log and a JSON
  `error` event.

### Dark and light

- The wallet is dark by default. The sun/moon button in the top bar, or Settings,
  switches the appearance, and the choice is remembered.

### Security

- **Repository:** GitHub secret scanning and push protection are enabled on
  `genoryn/genoryn`, so pushes that contain credentials are blocked.
- **Seed server:** the operating system's security updates are installed, including a
  new kernel (the server was rebooted onto it). The firewall allows only SSH and the
  peer-to-peer port; the admin RPC stays on loopback, and the node and miner run as an
  unprivileged service user under systemd sandboxing.
- **Node:** administrative endpoints answer HTTP 401 for a missing or wrong token.
- **Connections:** the connection library accepts plain HTTP only for literal loopback
  addresses, on every network; anything remote requires HTTPS.

### Upgrading

Run `GENORYN-Setup-0.4.0.exe` over your current installation. The wallet then starts a
mainnet node in `%USERPROFILE%\.genoryn\mainnet`. **Devnet coins do not carry over**:
the devnet was a test network. Create a new wallet for mainnet and write its 24 words
down offline. The old devnet data stays in `.genoryn\devnet` until you delete it. Nodes
older than 0.4.0 stay on the devnet and cannot connect to the mainnet.

### Verify before running

Every installer and archive has a matching `.sha256` file; each package contains
`SHA256SUMS` and `release-manifest.json` with the exact source commit. Packages are
**unsigned builds**, so Windows SmartScreen may warn before the first run.
