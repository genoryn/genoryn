**Development release for the public devnet. Not audited. Do not use real funds.**

GENORYN 0.2.0 turns the local development lab into a network people can join:
download, open the wallet, and your own full node starts and connects by itself.

### Network

- **Public devnet.** `genorynd` now listens on all interfaces by default and joins
  the shared devnet. Discovery accepts public peer addresses only; a node bound to
  loopback remains an isolated local lab with the previous behaviour.
- **Bootstrap seeds** from the built-in list (`apps/genoryn/src/seeds.rs`) and from
  [`seeds/devnet.txt`](https://github.com/genoryn/genoryn/blob/main/seeds/devnet.txt)
  in this repository are contacted at startup by public nodes, so new seed nodes can
  be announced without a release. `--no-default-seeds` opts out. Seeds only help
  nodes meet and are never consensus authorities.
- **Wildcard listeners are advertised correctly.** A peer listening on `0.0.0.0`
  is recorded at the address its connection was observed from, so peer exchange
  works for default-configured nodes.
- Nodes behind NAT or a VPN take part through outbound connections.

### Wallet

- **Locked means locked.** Nothing but the unlock screen is reachable until a wallet
  is unlocked. A running miner keeps mining while locked, and the lock screen says so.
- **Starts its own node** when none is running (once, at launch; `--auto-node off`
  disables it). Mining still only ever starts when you choose.
- **Readable node logs** open in their own window, with refresh and buttons to open
  the log file or its folder.
- **Balance updates automatically** as new blocks arrive. Automatic scans run in the
  background, back off as the chain grows and never interrupt a payment under review.
- **Update notices.** The wallet checks GitHub Releases when it opens and shows a
  notice when a newer version is published. Settings → Updates shows the installed
  version, checks on demand and displays release notes. Nothing is downloaded or
  installed automatically; the check can be turned off.
- **Several wallets at once.** Open up to eight wallets, switch between them from the
  wallet menu in the top bar and see the combined balance of every open wallet.
  Inactive wallets keep refreshing in the background; Lock closes all of them.
- **Transactions, organised.** Transfers and mining rewards are separate categories
  (transfers first), with search by transaction ID, memo, amount or block and filters
  for direction and confirmation status. Rows show dates, confirmations, memos, a
  copyable transaction ID and payment-proof export.
- **Choose wallet files with the system dialog.** Browse for a wallet to unlock, pick
  it from the wallets found in the folder, or name a new wallet and choose its folder
  (native dialogs on Windows).
- **Clearer wallet setup.** The wallet opens on Create when no wallet file exists,
  explains exactly why an action is unavailable (password length, mismatched
  confirmation, a 24-word recovery phrase, an existing or already open file, an
  invalid wallet name) and counts password characters rather than bytes.
- **New identity.** The GNR sign, a G crossed by two short vertical strokes, is the
  logo of the window, taskbar and executable and appears beside every amount. The
  sidebar uses monochrome vector icons.

### Brand

- A `branding/` folder with every logo variant (dark and light marks, the bare sign,
  wordmarks, banner), PNG exports from 16 to 1024 px, the Windows icon and usage rules.

### Release engineering

- Version 0.2.0 is defined once in `Cargo.toml`; packaging and the UI read it from there.
- Pushing a `vX.Y.Z` tag builds the Windows and Linux packages and attaches them to
  the GitHub Release with SHA-256 checksums.

### Verify before running

Each archive has a matching `.sha256` file, and every package contains
`SHA256SUMS` and `release-manifest.json` with the exact source commit. Packages are
**unsigned development builds**. See
[release verification](https://github.com/genoryn/genoryn/blob/main/docs/security/releases.md).

Windows needs the Microsoft Visual C++ v14 x64 runtime. Linux packages target
Ubuntu 24.04 x86-64.
