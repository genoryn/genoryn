**Development release for the public devnet. Not audited. Do not use real funds.**

GENORYN 0.2.1 installs like any Windows application, remembers your wallets and mines
with every CPU you give it.

### Windows installer

- **`GENORYN-Setup-0.2.1.exe`**: one file, no administrator rights. It adds GENORYN to
  the Start menu (and the desktop if you choose) and to Settings → Apps for uninstalling.
- **Updates in place.** Run a newer installer and it closes the running wallet, replaces
  the program and keeps your settings. The wallet's update notice now downloads the new
  installer directly, only from this repository and only for that exact version.
- **Your data is never touched.** Wallets and chain data stay in `%USERPROFILE%\.genoryn`
  through install, update and uninstall.
- **Visual C++ runtime.** If it is missing, the installer offers to download it from
  Microsoft.
- The portable `.zip` packages for Windows and Linux are still published.

### Wallet

- **Remembered wallets.** The wallets you had open come back at the next launch: the
  last active one is preselected, and one password can unlock all of them that share it.
  Wallets with another password wait under *Locked* in the wallet menu. Only file paths
  are stored, never passwords.
- **Mine with every core.** The CPU selector offers one thread per logical CPU (up to 16)
  and shows the memory it needs.

### Mining

- **No more stale work.** The miner abandons a block template within a second once
  another block takes its height, instead of searching on a stale parent until it finds
  a block that can no longer win.
- **Thread limit follows the CPU.** `genoryn-miner --threads` accepts one thread per
  logical CPU, up to 16 (256 MiB of RandomX light-mode cache each), instead of a fixed 4.
- **Resilient.** A busy proof worker or a restarting node makes the miner wait and retry
  instead of exiting.

### Network

- The first public seed node, `187.7.72.137`, is built in and published in
  `seeds/devnet.txt`.

### Verify before running

Every installer and archive has a matching `.sha256` file; each package contains
`SHA256SUMS` and `release-manifest.json` with the exact source commit. Packages are
**unsigned development builds**, so Windows SmartScreen may warn before the first run.
See [release verification](https://github.com/genoryn/genoryn/blob/main/docs/security/releases.md).
