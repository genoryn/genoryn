**Mainnet release. The software has not been independently audited: mine or hold only what you can afford to lose.**

GENORYN 0.6.2 makes the miner several times faster. Everyone who mines should update.

### Faster mining

- The miner now uses RandomX in full-memory ("fast") mode: all threads share one
  dataset of about 2 GiB instead of a 256 MiB cache each, so a hash no longer
  recomputes the data it reads. On a 24-thread desktop the hashrate went from
  136 H/s (4 threads) and 435 H/s (24 threads) to about 3,700 H/s with 24 threads.
- Mining starts at once. For about the first minute the dataset is built in the
  background while the miner hashes in the old light mode; then the current block
  is searched again in fast mode. The dataset is rebuilt only when the RandomX seed
  changes, every 2048 blocks (about 34 hours).
- The Mining page offers one thread per logical CPU, no longer at most 16. Fast mode
  needs about 2.3 GiB of memory in total, whatever the number of threads.
- If the dataset cannot be allocated, the miner says so in `genoryn-miner.log` and
  keeps mining in light mode. `genoryn-miner --randomx-mode light` keeps the old
  behavior; `GENORYN_RANDOMX_PORTABLE=1` still selects the portable interpreter.
- Mining progress reports name the RandomX mode in use (`randomx_mode`).

### Unchanged

Consensus, block validity, RandomX version and seed, difficulty, the peer protocol,
monetary rules, wallet files and chain data are unchanged. Nodes still verify every
block in light mode, and blocks mined in fast mode are byte-for-byte the blocks
light mode accepts: 0.6.2 works with 0.4.x, 0.5.x and 0.6.x nodes. Only the miner
and the Mining page changed.

To share the dataset between threads, the vendored RandomX Rust binding marks a
finished dataset as safe to share; native RandomX sources are unchanged. See
[ADR 0016](../adr/0016-fast-mode-mining.md).

### Upgrading

Run `GENORYN-Setup-0.6.2.exe` (or the Lite installer) over your current installation;
wallets and chain data are kept. The wallet's **Settings → Updates** card offers it too.
Stop mining before updating, then start it again and choose the number of threads.

GENORYN is not code-signed yet. If Windows 11's Smart App Control is on, the installer
explains how to turn it off. SmartScreen's "Windows protected your PC" prompt: choose
**More info → Run anyway**.

### Verify before running

Every installer and archive has a matching `.sha256` file; each package contains
`SHA256SUMS` and `release-manifest.json` with the exact source commit and edition.
Packages are **unsigned builds**.
