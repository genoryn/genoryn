# GENORYN 1.0.1

A maintenance release for Mainnet 1.0. Consensus, the emission schedule, the chain and
wallet files are unchanged; 1.0.1 and 1.0.0 nodes work together.

## Fixes

- **Quick mode over the real Tor network.** The wallet downloaded blocks with eight
  parallel connections, and every new Tor connection builds its own circuit to the onion
  service; on the public Tor network many of them failed and a first sync often did not
  finish. Downloads now use two connections that are kept and reused, and a transport
  error is retried up to six times with growing pauses (a wrong answer is never retried).
  Measured: a first Quick-mode sync of 90 blocks over Tor in 81 seconds.
- **A sync that no source confirmed is shown as possibly out of date.** If every source
  failed while downloading, 1.0.0 could show the last verified state (for a new wallet:
  height 0, balance 0) as current. Now it is current only when at least one source
  agrees with, served, or is behind the followed chain; otherwise it reads "last verified
  at block H".
- **Onion services recover by themselves.** A built-in onion service that stays
  unreachable for ten minutes is relaunched with the same key, so its address does not
  change. Seed and Quick-mode source operators should update.
