GENORYN 0.4.1 explains Windows 11's Smart App Control instead of failing with
"An Application Control policy has blocked this file" (code 4551).

### Smart App Control

GENORYN is not code-signed yet. Smart App Control blocks every unsigned program and has
no per-app exception, so with it on, GENORYN cannot start.

- **The installer checks first.** When Smart App Control is enforcing, setup stops
  before installing anything, explains why, and offers to open the Smart App Control
  settings. No half-working installation is left behind.
- **The wallet names the cause** if Windows blocks the node or the miner: Smart App
  Control or an application control policy, with the setting that resolves it.

**To use GENORYN on such a computer:** Windows Security → App & browser control → Smart
App Control settings → Off, then run the installer again. On some Windows versions Smart
App Control cannot be turned back on without reinstalling Windows.

SmartScreen's "Windows protected your PC" is a different, one-time prompt: choose
**More info → Run anyway**.

### Upgrading

Run `GENORYN-Setup-0.4.1.exe` over your current installation; wallets and chain data
are kept. Nodes and wallets of 0.4.0 and 0.4.1 are fully compatible.

### Verify before running

Every installer and archive has a matching `.sha256` file; each package contains
`SHA256SUMS` and `release-manifest.json` with the exact source commit. Packages are
**unsigned builds**.
