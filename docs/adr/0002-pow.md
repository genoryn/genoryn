# ADR 0002: RandomX versioned CPU proof of work

Use `randomx-rs = 1.6.0`, binding the established RandomX implementation.
GENORYN v1 selects a single explicit algorithm version, epoch-key derivation and
256-bit target comparison. Light verification uses approximately 256 MiB per
cache. The miner uses the same genuine algorithm in full-memory (fast) mode
([ADR 0016](0016-fast-mode-mining.md)), never a different validity rule. Supported CPU/JIT
execution optimization within light mode is covered by [ADR 0011](0011-randomx-execution-modes.md). No hash-only mock
backend is permitted in node consensus. CPU-friendly does not prove ASIC/GPU
resistance. Bound mining duration, thread count and verification concurrency.

[RandomX design and audits](https://github.com/tevador/RandomX) and
[Rust binding](https://docs.rs/randomx-rs/1.6.0/randomx_rs/) are the implementation
sources. Native dependencies contain unsafe/C++ code; GENORYN Rust forbids unsafe
code. Builds require C/C++ and CMake, including on Windows.

Difficulty is integer, retargeted every block over a bounded recent window,
with median-time-past and a future-time limit. This independent consensus
integration is experimental until adversarial simulations and external review.
