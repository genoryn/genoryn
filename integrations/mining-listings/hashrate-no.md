## What Hashrate.no asks for

> To be considered for listing, a coin needs to meet a few basic requirements: it should be
> available on one of our supported exchanges, have healthy trading volume, and have steady
> daily emission.

Since Hashrate V2 (June 2025) coins with less than $100 of daily emission or $1,000 of trading
volume are not shown with estimates. The coin form asks for block time, total block reward and
the percentages going to miners, masternodes and developers. Benchmarks are only accepted with
the overclock settings used (core and memory clocks or offsets, power limit, voltages).

| Requirement | Genoryn Krypton | Ready |
|---|---|---|
| Block time | 60 s | yes |
| Block reward | 5 GNR, 100 % to miners, 0 % masternodes, 0 % developers | yes |
| Steady daily emission | 7,200 GNR a day until block 2,100,000 | yes |
| A supported exchange with healthy volume | none: GNR trades only by BTC atomic swap | **no (blocker)** |
| Benchmarks with overclock settings | README hashrates have no overclock data | no |

## Can be done before a listing

Hashrate.no accepts benchmark submissions for coins it does not list yet. A benchmark needs the
real card, the miner version and every clock and power value; collect them on real hardware,
never estimate them.
