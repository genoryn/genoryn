Verify what you download

Every release publishes SHA256SUMS and SHA256SUMS.sig, a hybrid ML-DSA-87 + SLH-DSA-SHAKE-256s signature (key fingerprint e4567fb116258bdd, public key in docs/release-key.pub). Compare the hash of your file before running it.

certutil -hashfile genoryn-krypton-windows-x64.zip SHA256   # Windows
sha256sum -c SHA256SUMS                                     # Linux
krypton-release verify release-key.pub SHA256SUMS SHA256SUMS.sig   # post-quantum signature

Run a full node

kryptond
# API: http://127.0.0.1:30334/v1/info · P2P port 30333

Light wallets need no node at all. A full node validates every block, every STARK proof and every rule itself, and can serve light wallets.
